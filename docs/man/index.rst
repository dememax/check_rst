########################
check_rst manual pages
########################

These concise pages are the source for Sphinx's ``man`` builder.  The RST
files are canonical; generated roff is a build artifact and must not be edited
independently.

*****************
Command manuals
*****************

* :doc:`check_rst` — command selection, global options, phases, and status;
* :doc:`check_rst-check` — diagnostics and machine-readable reports;
* :doc:`check_rst-fix` — bounded in-place corrections;
* :doc:`check_rst-diff` — read-only correction preview;
* :doc:`check_rst-outline` — document structure;
* :doc:`check_rst-list-table` — table-source conversion;
* :doc:`check_rst-hierarchy` — the live adornment order;
* :doc:`check_rst-reports` — context, refs, and JSON-diff queries.

*****************
Concept manuals
*****************

* :doc:`check_rst-config` — repository configuration;
* :doc:`check_rst-json` — JSON report contract;
* :doc:`check_rst-formats` — native and bridge formats;
* :doc:`check_rst-workflow` — the safe edit-validation loop;
* :doc:`check_rst-rules` — deterministic and human decision boundaries.
